# GL.iNet GL-MT6000 — Flint 2

## Device
- Model: `GL.iNet GL-MT6000`
- Board: `glinet,gl-mt6000`
- Target: `mediatek/mt7986`
- OpenWrt: `21.02-SNAPSHOT`
- Kernel: `5.4.238`
- Architecture: `aarch64_cortex-a53`

## Preflight
```bash
ssh -i ~/.ssh/id_ed25519_flint4 -p 122 root@<router> 'echo OK'
```

## Port Layout
- swconfig mode
- LAN ports: `1`, `2`, `3`, `4`, `5`
- WAN: `eth1`

## VLAN Handling
- Uses `switch_vlan` sections in `network` UCI config
- Wizard sets port format like `6t 4t` plus untagged ports
- Bridge interface usually becomes `eth1.<VLAN>`

## WAN
- Usually single WAN on `eth1`
- Dual-WAN less common; still safe to run wizard

## VLAN Layout Example
| VLAN | Purpose | Subnet |
|---|---|---|
| 1 | Primary LAN | `192.168.1.0/24` |
| 20 | Guest | `192.168.20.0/24` |
| 30 | IoT | `192.168.30.0/24` |
| 50 | Work | `192.168.50.0/24` |

## Install Wizard
```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/zippyy/GL.iNet-VLAN-Wizard/main/install.sh)"
```

## Notes
- MT7986 is swconfig-based in current firmware family
- If your board has switched to DSA, update `MODE` detection in `install.sh`
