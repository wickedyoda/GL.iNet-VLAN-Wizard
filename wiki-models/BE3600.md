# GL.iNet BE3600

## Device
- Model: board reports `GL.iNet BE3600, Inc. IPQ5332/AP-MI04.1-C2`
- Board: `qcom,ipq5332-ap-mi04.1-c2`
- Target: `ipq53xx/generic`
- OpenWrt: `23.05-SNAPSHOT`
- Kernel: `5.4.213`
- Architecture: `aarch64_cortex-a53_neon-vfpv4`

## Preflight
```bash
ssh -i ~/.ssh/id_ed25519_flint4 -p 122 root@<router> 'echo OK'
```

## Port Layout
- DSA mode
- LAN via `eth1`
- WAN via `eth0`

## Known Interfaces
- `br-lan` often at `192.168.65.1/24`
- `tailscale0`, `sta1`, `wgclient1`, and multiple Wi-Fi VAPs may exist

## VLAN Layout Example
| VLAN | Purpose | Subnet |
|---|---|---|
| 1 | Primary LAN | `192.168.1.0/24` |
| 20 | Guest | `192.168.20.0/24` |
| 30 | IoT | `192.168.30.0/24` |
| 50 | Work | `192.168.50.0/24` |

sh -c "$(curl -fsSL https://raw.githubusercontent.com/zippyy/GL.iNet-VLAN-Wizard/main/install.sh)"

- If existing LAN subnet conflicts with `192.168.<VLAN>`, adjust final config or use custom profile
- Verify `eth1` vs bridge naming before applying config live
