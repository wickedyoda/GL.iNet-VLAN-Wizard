# GL.iNet GL-BE10000 — Slate 7 Pro

## Device
- Model: `GL.iNet GL-BE10000`
- Board: `glinet,gl-be10000`
- Target: `mediatek/mt7987`
- OpenWrt: `21.02-SNAPSHOT`
- Kernel: `5.4.281`
- Architecture: `aarch64_cortex-a53`
- Hostname example: `SlateMyBrain`
- Tailscale example: `slatemybrain.tail99133.ts.net`

## Preflight
```bash
ssh -i ~/.ssh/id_ed25519_flint4 -p 122 root@<router> 'echo OK'
```

## Port Layout
- DSA mode
- LAN ports: `lan1`, `lan2`, `lan3`, `lan4`
- WAN: `eth0`

## Wireless
- Multiple radios/VAPs common: `ra0`, `rai0`, `rax0`, etc.
- May expose guest bridge `br-guest`

## Typical Layout Example
| VLAN | Purpose | Subnet |
|---|---|---|
| 1 | Primary LAN | `192.168.1.0/24` |
| 20 | Guest | `192.168.20.0/24` |
| 30 | IoT | `192.168.30.0/24` |
| 50 | Work | `192.168.50.0/24` |

## Install Wizard
```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/zippyy/GL.iNet-VLAN-Wizard/main/install.sh)"
```

## Notes
- Travel/router-on-the-go installs often use client-mode WAN first; convert WAN mode only after validation
- Guest bridge may already exist; wizard appends bridge-vlan config cleanly in DSA mode
